# MeetingApp Frontend

This directory contains the frontend user interface for **MeetingApp**, built with **React 19**, **Material-UI (MUI)**, **Socket.IO Client**, and **WebRTC**.

For complete setup instructions, features overview, API documentation, and backend details, please refer to the main repository [README.md](../README.md).

## Quick Start

In this directory, you can run:

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `build` folder.
